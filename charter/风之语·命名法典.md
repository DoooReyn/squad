# 风之语·命名法典

> *"知晓真名，方能召唤力量。命名非小事，是万物的基石。"*
> —— 吟游诗人 小柯

> 本法典与「风之歌·代码乐章」配套使用，共同构成项目的命名规范。

---

## 核心原则

> *"名字应该揭示意图，而非隐藏意图。"*

1. **见名知意** — 好的名字不需要注释解释
2. **一致即正义** — 同类事物用同一种命名风格
3. **避免缩写** — 除非是公认的缩写（如 HP、MP、URL）
4. **读音自然** — 名字应该易于朗读和记忆

## 文件命名

### TypeScript 文件

```typescript
// ✅ 好的：kebab-case，小写+连字符
// hero.ts
export class Hero {}

// battle-manager.ts
export class BattleManager {}

// game-state-machine.ts
export class GameStateMachine {}

// ❌ 坏的：使用 PascalCase（跨平台风险）
// Hero.ts
export class Hero {}

// ❌ 坏的：使用 camelCase
// heroManager.ts
export class BattleManager {}
```

### 配置文件

```typescript
// ✅ 好的：使用 kebab-case，小写+连字符
// game-config.ts
export const gameConfig = {};

// hero-data.json
export const heroData = {};

// ❌ 坏的：配置文件用 PascalCase
// GameConfig.ts
```

### 资源文件（Cocos Creator）

```
assets/
├── Textures/
│   ├── hero-avatar.png      ✅ kebab-case
│   └── battle-bg.jpg        ✅ kebab-case
├── Audio/
│   ├── bgm-battle.mp3       ✅ 带前缀区分类型
│   └── sfx-jump.wav         ✅ 带前缀区分类型
└── Spine/
    └── hero-run.json        ✅ 描述用途
```

## 类与接口命名

### 类（Class）

```typescript
// ✅ 好的：PascalCase
class Hero {}
class BattleManager {}
class GameStateMachine {}

// ❌ 坏的：其他风格
class hero {}             ❌ 全小写
class battle_manager {}   ❌ snake_case
class battleManager {}    ❌ camelCase
```

### 抽象类

```typescript
// ✅ 好的：以 Abstract 开头
abstract class AbstractHero {}
abstract class AbstractManager {}

// ✅ 或以 Base 开头
abstract class BaseHero {}
abstract class BaseManager {}
```

### 接口（Interface）

```typescript
// ✅ 好的：PascalCase，可选 I 前缀
interface HeroConfig {}
interface IHeroConfig {}  // 带I前缀（可选拥护）
interface BattleOptions {}

// ❌ 坏的：不一致
interface heroConfig {}   ❌ 全小写
interface HERO_CONFIG {}  ❌ 全大写
```

### 泛型参数

```typescript
// ✅ 好的：单个大写字母，或有意义的 PascalCase
function create<T>(value: T): T {}
function map<TInput, TOutput>(fn: (x: TInput) => TOutput) {}
function merge<TConfig, TData>(config: TConfig, data: TData) {}

// ❌ 坏的：无意义的单字母
function create<t>(value: t): t {}  // 小写单字母
function merge<T1, T2>() {}         // 无意义的数字
```

## 函数与方法命名

### 普通函数

```typescript
// ✅ 好的：camelCase，动词开头
function getHeroById(id: string): Hero {}
function createHero(config: HeroConfig): Hero {}
function updateHealth(value: number): void {}

// ✅ 好的：布尔返回值用 is/has/can 开头
function isAlive(): boolean {}
function hasWeapon(): boolean {}
function canAttack(): boolean {}

// ❌ 坏的：名词开头
function heroById(): Hero {}
function heroCreate(): Hero {}

// ❌ 坏的：拼音或无意义缩写
function getYx(): void {}  // 游戏的拼音
function getData1(): void {} // 无意义数字
```

### Cocos Creator 生命周期方法

```typescript
// ✅ 好的：使用 Cocos 定义的标准名称
protected onLoad(): void {}
protected start(): void {}
protected update(dt: number): void {}
protected lateUpdate(dt: number): void {}
protected onDestroy(): void {}
protected onEnable(): void {}
protected onDisable(): void {}
```

### 事件处理函数

```typescript
// ✅ 好的：on + 事件名
protected onClick(event: Event): void {}
protected onCollisionEnter(other: Collider): void {}
protected onHeroDeath(hero: Hero): void {}

// ❌ 坏的：不清晰
protected click(): void {}
protected handleEvent(): void {}
```

## 变量命名

### 普通变量

```typescript
// ✅ 好的：camelCase
let heroName = '小柯';
let currentHealth = 100;
let maxLevel = 99;

// ❌ 坏的：其他风格
let hero_name = '小柯';     // snake_case
let HeroName = '小柯';      // PascalCase
let HERO_NAME = '小柯';     // UPPER_CASE
```

### 布尔变量

```typescript
// ✅ 好的：is/has/can/should 前缀
let isAlive = true;
let hasWeapon = false;
let canAttack = true;
let shouldUpdate = false;

// ❌ 坏的：无前缀
let alive = true;
let weapon = false;
```

### 私有成员

```typescript
// ✅ 好的：下划线前缀
class Hero {
  private _hp: number = 100;
  private _mp: number = 50;

  get hp(): number {
    return this._hp;
  }
}

// ❌ 坏的：无前缀（难以区分公开/私有）
class Hero {
  private hp: number = 100;  // 看起来是公开的
}
```

### 保护成员

```typescript
// ✅ 好的：无前缀（protected 关键字已表明访问级别）
class Hero {
  protected state: string = 'idle';
  protected level: number = 1;

  protected updateState(): void {}
  protected getLevel(): number {}
}

// ❌ 坏的：与私有成员混淆（都用 _ 前缀）
class Hero {
  protected _state: string = 'idle';  // 看起来像私有的
  protected _updateState(): void {}   // 方法带前缀很奇怪
  private _hp: number = 100;
}
```

### 静态成员

```typescript
// ✅ 好的：PascalCase（与类名风格一致）
class Journal {
  private static MainLevel: LogLevel = LogLevel.INFO;
  private static Loggers: Map<string, Logger> = new Map();

  public static Acquire(category: string): Logger {}
  public static SetMainLevel(level: LogLevel): void {}
}

// ❌ 坏的：使用其他命名风格
class Journal {
  private static mainLevel: LogLevel;     // camelCase
  private static _mainLevel: LogLevel;    // 带下划线
  private static MAIN_LEVEL: LogLevel;    // UPPER_SNAKE_CASE

  public static acquire() {}              // camelCase
  public static _setMainLevel() {}       // 带下划线
}
```

**要点：**
- 静态成员变量和静态方法都使用 PascalCase
- 这与类名的风格保持一致，清晰表明"类级"身份
- 与实例成员（camelCase）形成对比，易于区分

## 常量命名

### 全局常量

```typescript
// ✅ 好的：UPPER_SNAKE_CASE
const MAX_HP = 9999;
const DEFAULT_MP = 100;
const BATTLE_DURATION = 60;

// ❌ 坏的：其他风格
const maxHp = 9999;
const MaxHp = 9999;
const max_hp = 9999;
```

### 类内常量

```typescript
// ✅ 好的：静态常量用 UPPER_SNAKE_CASE
class GameConfig {
  public static readonly MAX_LEVEL = 99;
  public static readonly SAVE_KEY = 'squad_save';
}

// ✅ 或私有静态常量
class Hero {
  private static readonly BASE_HP = 100;
  private static readonly BASE_MP = 50;
}
```

### 枚举

```typescript
// ✅ 好的：PascalCase 枚举名 + PascalCase 成员
enum GameState {
  Ready = 'ready',
  Running = 'running',
  Paused = 'paused',
  Ended = 'ended',
}

enum HeroType {
  Warrior = 'warrior',
  Mage = 'mage',
  Archer = 'archer',
}

// ❌ 坏的：全大写成员
enum GameState {
  READY = 'ready',   // 不推荐
  RUNNING = 'running',
}
```

## 类型别名命名

```typescript
// ✅ 好的：PascalCase，描述性名称
type HeroID = string;
type JSONObject = Record<string, unknown>;
type HeroState = 'idle' | 'run' | 'attack';

// ✅ 好的：回调函数用 Callback/Handler 结尾
type UpdateCallback = (dt: number) => void;
type CollisionHandler = (other: Collider) => void;

// ❌ 坏的：不够描述性
type ID = string;          // ID 什么？
type Obj = Record<string, unknown>; // Obj 是什么对象？
type State = string;       // 太宽泛
```

## Cocos Creator 特殊命名

### 组件装饰器

```typescript
// ✅ 好的：装饰器名与类名一致
@ccclass('Hero')
export class Hero extends Component {}

@property({ tooltip: '移动速度' })
public moveSpeed: number = 100;

// ❌ 坏的：装饰器名与类名不一致
@ccclass('hero')
export class Hero extends Component {}
```

### 节点引用

```typescript
// ✅ 好的：节点引用用 Node 后缀
@property({ type: Node })
public heroNode: Node = null!;

// ✅ 好的：组件引用直接用组件名
@property({ type: Sprite })
public heroSprite: Sprite = null!;

@property({ type: Animation })
public heroAnimation: Animation = null!;
```

## 临时变量命名

```typescript
// ✅ 好的：有意义的临时变量
for (let index = 0; index < heroes.length; index++) {
  const hero = heroes[index];
}

// ✅ 好的：循环中的单字母变量要有约定（i=index, k=key, v=value）
for (let i = 0; i < count; i++) {}

for (const [key, value] of Object.entries(map)) {}
for (const [k, v] of Object.entries(map)) {} // 简写时可接受

// ❌ 坏的：无意义的单字母
const a = getHero();
const temp = getHero();
const data = getHero();
```

## 避免的命名

### 避免误导

```typescript
// ❌ 坏的：名字与实际不符
let heroList: Hero[] = []; // 是数组不是 List
let heroData: string = ''; // 不是数据，是字符串
let heroMap: Hero[] = [];  // 不是 Map，是数组

// ✅ 好的：准确描述类型
let heroes: Hero[] = [];
let heroName: string = '';
let heroArray: Hero[] = [];
```

### 避免魔法数字

```typescript
// ❌ 坏的：直接使用魔法数字
if (hero.hp < 100) {
  hero.levelUp();
}

// ✅ 好的：使用常量
const LEVEL_UP_THRESHOLD = 100;
if (hero.hp < LEVEL_UP_THRESHOLD) {
  hero.levelUp();
}
```

### 避免拼音

```typescript
// ❌ 坏的：使用拼音
let yx = '游戏';
let wq = '武器';
let gw = '岗位';

// ✅ 好的：使用英文
let game = 'game';
let weapon = 'weapon';
let position = 'position';
```

## 命名一致性

### 相关概念保持一致

```typescript
// ✅ 好的：同一组概念用同一套词汇
class Hero {
  getHealth(): number {}
  setHealth(value: number): void {}
}

class Enemy {
  getHealth(): number {}
  setHealth(value: number): void {}
}

// ❌ 坏的：概念不一致
class Hero {
  getHp(): number {}      // Hp
  setHealth(value: number): void {}  // Health
}

class Enemy {
  getHealth(): number {}  // Health
  setHP(value: number): void {}  // HP
}
```

### 动词选择规范

| 动词 | 用途 |
|------|------|
| `get` | 获取值（无副作用） |
| `set` | 设置值 |
| `is/has/can` | 返回布尔值 |
| `create` | 创建新对象 |
| `init` | 初始化 |
| `start` | 启动流程 |
| `stop` | 停止流程 |
| `update` | 更新状态 |
| `render` | 渲染显示 |
| `handle/process` | 处理数据或事件 |
